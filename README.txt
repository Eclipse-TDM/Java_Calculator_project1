Java Scientific CalculatorA desktop scientific calculator built with Java Swing and AWT, styled after the iOS calculator interface. Originally built from a foundational GUI tutorial, this version completes the homework extensions by adding square root evaluation, single-digit deletion, scientific functions, and input/error handling.FeaturesStandard & Utility ControlsBasic Arithmetic: Addition (`+`), subtraction (`-`), multiplication (`×`), and division (`÷`) with zero-division error handling.Display & Edit Controls: All Clear (`AC`), sign toggle (`+/-`), percentage (`%`), and single-digit backspace (`⌫`) to delete one character at a time.Dynamic Display Scaling: Adjusts display font size automatically as output length increases so numbers remain readable without clipping.Scientific & Homework ExtensionsSquare Root & Powers: Square root (`√`) with negative-input validation, square (`x²`), and custom exponentiation (`xʸ`).Trigonometry & Logarithms: Degree-based `sin`, `cos`, and `tan` (with undefined angle handling at odd multiples of `90°`), base-10 logarithm (`log`), and absolute value (`|x|`).Tech StackLanguage: JavaGUI Library: Java AWT & Swing
